## ✨ ძირითადი ფუნქციონალი:
- 🌸 **Botanical 3D Dandelion Entrance Portal** — ინტერაქციული 3D დენდელიონის საწყისი პორტალი;
- 📱 **სრული მობილური ოპტიმიზაცია (Mobile First)** — ადაპტური ჰამბურგერ მენიუ, სენსორული ჟესტები;
- 🤖 **მეტაბოტი (MetaBot AI)** — ინტეგრირებული ქართულენოვანი ვირტუალური ასისტენტი სწრაფი კითხვებითა და პასუხებით;
- 📜 **მეტაფორას მანიფესტი (Section 5)** — ცოცხალი 3D მბრუნავი დენდელიონის ფიგურა, ხმოვანი მანიფესტის აუდიო-ფლეიერი და ეკვალაიზერი;
- 🎨 **დინამიური ფერების გადამრთველი** — Teal (ზურმუხტისფერი) ⇄ Plum (ქლიავისფერი);
- 🖼️ **სუფთა ფოტოგალერეა** — თანამედროვე ფილტრებითა და ოპტიმიზებული WebP გამოსახულებებით;
- 📖 **ბლოგი** — 3D კინეტიკური ფიგურითა და რჩეული სტატიებით;
- 📅 **Glassmorphism ონლაინ ჯავშნის მოდალი**.
